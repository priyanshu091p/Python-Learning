# 🖨️ print() Function

The `print()` function is used to display output on the screen.

Example:

```python
print("Hello, World!")
```

Output:

```
Hello, World!
```

---

# 📦 Variables

Variables are used to store data values in Python.

Example:

```python
name = "Priyanshu"
age = 20

print(name)
print(age)
```

Output:

```
Priyanshu
20
```

---

# 🔢 Data Types

Python supports different types of data.

## 1. Integer (int)

Used to store whole numbers.

Example:

```python
age = 20
```

---

## 2. Float (float)

Used to store decimal numbers.

Example:

```python
height = 5.8
```

---

## 3. String (str)

Used to store text.

Example:

```python
name = "Python"
```

---

## 4. Boolean (bool)

Stores True or False values.

Example:

```python
is_student = True
```

---

# ⌨️ input() Function

The `input()` function is used to take input from the user.

Example:

```python
name = input("Enter your name: ")

print(name)
```

---

# 🔄 Type Casting

Type casting is used to convert one data type into another.

## int()

Convert value into integer.

Example:

```python
age = int(input("Enter age: "))
```

---

## float()

Convert value into decimal number.

Example:

```python
price = float(input("Enter price: "))
```

---

## str()

Convert value into string.

Example:

```python
number = str(100)
```
